# 🚀 Six Sense Technologies Website

A modern, responsive, and interactive website built with **React.js** for **Six Sense Technologies**. The website showcases digital solutions, mentorship programs, training services, company achievements, and contact information through an engaging user experience.

## 📌 Features

* Responsive design for desktop, tablet, and mobile devices
* Modern and attractive UI/UX
* Interactive hero section with carousel
* Digital Solutions and Mentorship Services showcase
* Animated service cards and statistics section
* Smooth scrolling navigation
* Contact form for user inquiries
* Professional company information and social media links
* Optimized and reusable React components

## 🛠️ Technologies Used

* React.js
* JavaScript (ES6+)
* HTML5
* CSS3
* Bootstrap 5
* Bootstrap Icons
* Font Awesome
* Responsive Web Design

## ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/yourusername/six-sense-technologies.git
```

Navigate to the project directory:

```bash
cd six-sense-technologies
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm start
```

The application will run on:

```bash
http://localhost:3000
```
